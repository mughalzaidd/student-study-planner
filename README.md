# 📚 Student Study Planner

A simple and responsive web application that helps students organize their study tasks, manage their schedule, and track their progress.

## 🌟 Features

- Add study tasks
- Select subjects
- Set task dates
- Mark tasks as completed
- Delete tasks
- Filter pending and completed tasks
- Automatic progress calculation
- Dashboard with task statistics
- Weekly study timetable
- Study tips
- Data saved automatically using Local Storage
- Responsive design for mobile and desktop

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
